# CIO Kongress 2026 — Multiagenten-Architektur & die Machtverschiebung der IT

**Workshop (50 min) · Kongress-Motto „Co-Intelligence" · Zielgruppe: C-Level / IT-Entscheider**

Referenten: **Linus Kohl** (Organisation & Governance) · **Daniel Valtiner** (technischer Deep Dive)

> Leitfrage: **Wenn Softwareentwicklung demokratisiert wird — was bleibt dann eigentlich noch exklusiv in der IT?**
